## Run it

```bash
tools/bazel.sh test //services/ouroboros/miners/_template:miner_test
tools/bazel.sh build //services/ouroboros/miners/_template:miner
bazel-bin/services/ouroboros/miners/_template/miner.exe findings --knee 468 'services/ouroboros/miners/_template/fixtures/*/events.jsonl'
bazel-bin/services/ouroboros/miners/_template/miner.exe mutate services/ouroboros/miners/_template/fixtures/labels.tsv 'services/ouroboros/miners/_template/fixtures/*/events.jsonl'
bazel-bin/services/ouroboros/miners/_template/miner.exe backtest services/ouroboros/miners/_template/fixtures/labels.tsv '~/.local/state/csf/harness/*/events.jsonl'
```

The `mutate` verb prints `mutation.md`: every mutant of the rules and labels
with its outcome, and the score; `--json` prints the record the
[ops view](../../../../csf/docs/generated/ontology_cgen.md#term-ops_view)'s
series reads instead. The last command [backtests](../../../../csf/docs/generated/ontology_cgen.md#term-backtest) the same labels over every
harness run on the machine. The knee candidates are then the scores of all
gated runs, not just the three fixtures.
