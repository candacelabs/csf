# NO-SELF-MERGE, enforcement miner

<!-- agent-drafted (#379): awaiting operator approval -->

This [miner](../../../../csf/docs/generated/ontology_cgen.md#term-miner) flags pull requests when the author is the same session that
merged it, and no independent verdict from a different session exists in the
PR comments (ticket #249). It prevents orchestrator-authored PRs from being
merged without external code review.

| PR | Author | Merger | Independent verdict | Fires |
|---|---|---|---|---|
| #226 | orchestrator | orchestrator | none | yes: `refused(226)` |
| #245 | orchestrator | orchestrator | none | yes: `refused(245)` |
| #250 | orchestrator | orchestrator | from security-reviewer-1 | no: has verdict |

## Run it

```bash
tools/bazel.sh test //services/ouroboros/miners/no_self_merge:miner_test
tools/bazel.sh build //services/ouroboros/miners/no_self_merge:miner
bazel-bin/services/ouroboros/miners/no_self_merge/miner.exe findings 'services/ouroboros/miners/no_self_merge/fixtures/*/events.jsonl'
bazel-bin/services/ouroboros/miners/no_self_merge/miner.exe backtest services/ouroboros/miners/no_self_merge/fixtures/labels.tsv 'services/ouroboros/miners/no_self_merge/fixtures/*/events.jsonl'
```
