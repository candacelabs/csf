# Router v1 two arms

<!-- agent-drafted (#236): awaiting operator approval -->

This [miner](../../../../csf/docs/generated/ontology_cgen.md#term-miner) checks that every routing decision uses one of the two allowed arms:
attach_warm (attach to an existing conversation with the same ticket),
attach_topic (attach to an existing conversation with overlapping title),
or fresh (open a new conversation). It flags decisions that use any other arm
(#236).

| Instance | Arm | Valid | Fires |
|---|---|---|---|
| 0811bf5b... | attach_warm, attach_topic | yes | no: both valid arms |
| 252552ad... | attach | no | yes: invalid arm |
| 3321228e... | new | no | yes: invalid arm |

## Files

| File | Copy it | Fill it |
|---|---|---|
| `extract.ml` | yes | **yes**: `extract` and the `miner` record (name, package, verdicts) |
| `rules.dl` | yes | **yes**: the ticket's predicate, with its `/* predicate */` block |
| `main.ml` | yes | no: one line, `Contract.main Extract.miner` |
| `miner_test.ml` | yes | no: rules are sound, labels fire as labeled, FN = 0, `backtest.md` is current |
| `BUILD.bazel` | yes | no |
| `fixtures/` | no | your labeled instances, laid out like the corpus: `fixtures/<instance>/<file>` and `labels.tsv` |
| `backtest.md` | no | generated by the command in its last row |

## Run it

```bash
tools/bazel.sh test //services/ouroboros/miners/router_v1_two_arms:miner_test
tools/bazel.sh build //services/ouroboros/miners/router_v1_two_arms:miner
bazel-bin/services/ouroboros/miners/router_v1_two_arms/miner.exe findings 'services/ouroboros/miners/router_v1_two_arms/fixtures/*/events.jsonl'
bazel-bin/services/ouroboros/miners/router_v1_two_arms/miner.exe backtest services/ouroboros/miners/router_v1_two_arms/fixtures/labels.tsv 'services/ouroboros/miners/router_v1_two_arms/fixtures/*/events.jsonl'
```

The last command [backtests](../../../../csf/docs/generated/ontology_cgen.md#term-backtest) the labeled instances. To [backtest](../../../../csf/docs/generated/ontology_cgen.md#term-backtest) over every harness
run on the machine, use `~/.local/state/csf/harness/*/events.jsonl` in place of
the fixtures path.
